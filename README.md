# B2 English Vocabulary Game 🎮

An interactive, gamified web quiz designed to help B2-level English students master tricky prepositions, phrasal verbs, and adjective prefixes.

## Features
- **Round 1:** Prepositions & Phrasal Verbs (with instant grammar explanations).
- **Round 2:** Adjective Prefixes (`im-`, `un-`, `in-`) sorting challenge.
- **Gamified Experience:** Live score tracking, streak multipliers, and celebratory animations!
